# 龙猫放置 · 挂机收益计算器

把「去哪张图练级 / 打钱」这件事算清楚：读你队伍的真实属性，选食物 BUFF 看加成后数据，
对 47 张图排经验/h 与金币/h，并用你在游戏里的真实挂机数据把估算值替换成实测值。

---

## 一、三个文件分别是什么

| 文件 | 作用 |
|---|---|
| `龙猫收益计算器-单文件.html` | **主产物**，双击/手机里直接打开就能用，无需联网、无需服务器 |
| `index.html` + `data.js` + `app.js` | 同一套页面的拆分版，给 GitHub Pages 用（手机随时打开、可更新） |
| `bridge.user.js` | 桥接脚本：装在 Userscripts / Tampermonkey 里，负责「读真实属性」+「按地图采样」 |
| `build_data.py` / `build_single.py` | 数据预聚合与单文件打包脚本（游戏改版后重新跑一次即可） |

数据和公式全部来自游戏本体的静态表与客户端源码，不是估的：

- 防御减伤 `x/(1000+x)`
- 出手间隔 `1.5s / 攻速`
- 刷新等待 `5s / 移速`
- 每波 `spawnMin??1 ~ spawnMax??4` 只
- 一次伤害的完整顺序：命中判定 → 伤害浮动 → 暴击 → 减「物减/10」→ 按防御减伤 → 力量加成(`+0.08%/点`) → 总伤害加成 → 取整
- 经验 = `怪物经验 × 经验倍率 × 等级差系数`，等级差 ≥3 起每 3 级掉 10%（差 30 级归零）
- 掉落：`independent` 逐条独立判定；`group_pick_1` 整池概率 = 池内第一条的 chance、命中后池内**等概率**选一

**没有计入的**：主动技能的伤害与冷却、召唤物、装备触发的额外效果。
所以「估」会偏低，用页面上的 **伤害系数 k** 调准，或者等实测数据替换。

## 三、装桥接脚本（自动读真实属性 + 自动采样）

### 步骤

1. 打开 `bridge.user.js`，**先改一行**：把开头的
   ```js
   pageUrl: 'https://linsaey.github.io/longmao-farm-calculator/',
   ```
   改成你实际放计算器页面的地址（用 GitHub Pages 时就是它；不做 Pages 就不用改，用「复制数据」那条路）。
2. 在 iPhone 的 **Userscripts** App 里新建脚本，把 `bridge.user.js` 全文粘进去保存。
   - 它和「龙猫放置 · 布局调节台」**并存互不干扰**：调节台管样式，这个只管读数和采样。
   - 两个脚本都装在 Userscripts 里，各自独立，不会抢标签。
3. 打开游戏 `http://43.142.100.84:8080`，右下角会出现一条浮标「收益桥」：
   - 显示「采集 N 分钟 · 图 xxx」表示在正常工作
   - 显示「未登录或读不到存档」表示游戏没登录 / 存档没读到
4. 你在哪张图挂机，它就在哪张图累计；**切图自动换**，不用管。

### 把数据送进计算器（两条路，哪条通用哪条）

| 方式 | 操作 | 适用 |
|---|---|---|
| **自动注入**（推荐） | 计算器页面用 GitHub Pages 打开，桥接脚本的 `@match` 覆盖了它 → 页面顶部自动出现「数据来源 · 游戏数据」条，点「用这份游戏数据」即可 | 页面和脚本在同一个浏览器里 |
| **复制粘贴**（兜底，100% 可用） | 浮标点「复制数据」→ 打开计算器页面 → 展开「粘贴桥接脚本导出的数据」→ 粘进去 → 点「导入」 | Userscripts 不支持跨域共享存储时 |

采样数据会随导入一起存进页面本地（localStorage），下次打开不用再粘。

## 四、放 GitHub Pages（可选，但手机长期用最省事）

1. 在 GitHub 新建仓库 `longmao-farm-calculator`（Public，**不要**勾 README）。
2. 把本目录的 `index.html`、`data.js`、`app.js` 推到 `main` 分支根目录。
3. 仓库 Settings → Pages → Source 选 `main` / `(root)` → 保存。
4. 一分钟后访问 `https://<你的用户名>.github.io/longmao-farm-calculator/`。
5. 回到 `bridge.user.js` 把 `pageUrl` 改成这个地址。

## 五、页面上每个数字怎么来的

- **经验/h、直掉金币/h、含掉落合计/h**：按你填的真实属性 + 该地图怪物逐只算，再乘每波只数和刷新等待。
- **每波约 N 秒**：`Σ(怪物HP/队伍输出) × 每波只数 + 5/移速`。
- **升一级约 X 小时**：`当前等级 expToNext / 经验/h`（等级取队伍平均）。
- **掉落表**：每只怪展开后有卖价与期望件/h，稀有物只计数不计金。
- **`估` / `实测`**：实测来自桥接脚本定时读存档的 exp/gold 差值，按地图分段累计；
  某张图实测满 1 分钟就会从「估」升级为「实测」，并优先用于排序。

### 校准

- **伤害系数 k**：模型默认只算普通攻击，主动技能没算。挂过图后，用「实测每波耗时」对比模型值，
  把 k 调到两者接近即可（大致的经验：技能越满、触发越多，k 越大）。
- **移速覆盖**：填 0 表示用角色自身的移速；填具体百分比可临时模拟喝移速药。

## 六、已知限制（写清楚，不藏）

1. **主动技能未计入**，模型对技能流角色会偏低，必须用 k 或实测校正。
2. **掉落期望**按客户端 `Nv()` 的真实语义算，但装备类的「词条/稀有判定」不参与定价。
3. **实测靠存档差值**，所以只反映 exp / gold；掉落物的件数不进实测（要进得逐件读背包）。
4. **iOS 的 Userscripts 是否支持跨站共享 GM 存储未知** → 所以保留了「复制粘贴」这条路。
5. 游戏改版后表结构/公式可能变，重跑 `build_data.py` 再 `build_single.py` 即可刷新。
